# 📚 Data Structures and Algorithms – UBB Course Project

This repository contains my implementations of various **Abstract Data Types (ADTs)** and fundamental **algorithms**, developed as part of the *Data Structures and Algorithms* course at **Babeș-Bolyai University (UBB)**.

## 📌 Course Overview

The course emphasizes both theoretical foundations and practical implementation of data structures and algorithms. It provides the essential tools to solve complex computational problems efficiently and to understand the internal workings of standard data handling structures.

## ✅ Implemented Topics

### Abstract Data Types (ADTs)
- 🔹 `SortedMultiMap` (using Static Linked List with Arrays - SLLA)
- 🔹 `Dynamic Array`
- 🔹 `Stack`, `Queue`, `Deque`
- 🔹 `Hash Table`
- 🔹 `Binary Search Tree`, `Heap`
